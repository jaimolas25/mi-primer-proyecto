# mi-primer-proyecto

Página publicada con GitHub Pages.

- `index.html`: catálogo y tasador de libros (escáner de ISBN).
- `arena.html`: **Arena Brawl**, un juego de combate 3 contra 3 en vista cenital, hecho con HTML5 Canvas y sin dependencias.
  - Modo *Caza de cristales*: reúne 10 cristales de la mina central y aguanta 15 segundos.
  - 4 luchadores originales (Roca, Vega, Píxel y Lúa) con ataque y súper propios.
  - Bots con inteligencia artificial en tres dificultades, arbustos para esconderse, muros, curación pasiva y reaparición.
  - Controles de teclado y ratón, y joysticks táctiles para móvil.

# ============================================================
#  Canales y listas de YouTube que quieres seguir sin conexión
# ============================================================
#
#  Escribe una dirección por línea. Las líneas que empiezan por "#"
#  son comentarios y se ignoran.
#
#  Valen estos tipos de direcciones:
#    - Canal:        https://www.youtube.com/@nombredelcanal
#    - Canal (ID):   https://www.youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx
#    - Lista:        https://www.youtube.com/playlist?list=PLxxxxxxxxxxxxxxxx
#    - Vídeo suelto: https://www.youtube.com/watch?v=xxxxxxxxxxx
#
#  Cada día el programa "actualizar.py" mira estas direcciones,
#  descarga los vídeos nuevos y los deja listos en la carpeta "videos/".
#
#  Ejemplos (borra el "#" del principio para activarlos):

# https://www.youtube.com/@Kurzgesagt
# https://www.youtube.com/@veritasium
# https://www.youtube.com/@QuantumFracture

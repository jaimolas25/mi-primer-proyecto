Transcriptor de YouTube

Pega el enlace de un vídeo y obtén su transcripción. Copia, busca y descarga en TXT, SRT o VTT.

Usar como API desde otra web o programa

Este servidor también funciona como proxy: cualquier programa puede pedirle la transcripción.

Parámetros: url (enlace o ID), lang (p. ej. es,en), format (json, text, srt, vtt), timestamps=1, download=1. También /api/languages?url=... lista los idiomas disponibles.

Los subtítulos los proporciona YouTube; este servicio solo los reordena para que puedas leerlos.
